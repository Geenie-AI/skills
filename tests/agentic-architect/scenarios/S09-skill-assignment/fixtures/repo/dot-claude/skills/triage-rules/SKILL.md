---
name: triage-rules
description: Use when a request mentions a client name or a regulated market; the routing rules that override the default classification.
---

A named client with an active engagement routes to investigate. A regulated market (pharma, defence, financial services) routes to investigate and flags for compliance review. Requests from unknown senders route to decline with a referral to the intake form.
Done when the class and flags are set per these rules.

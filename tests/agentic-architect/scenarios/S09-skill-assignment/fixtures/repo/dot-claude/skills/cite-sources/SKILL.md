---
name: cite-sources
description: Use when writing or checking citations in findings or briefs; defines the house citation format and what counts as a source.
---

Format: `[n]` in text, numbered list at the end with title, publisher, date, URL or note path. A note path counts as a source only if the note itself cites a primary source. A claim with no source is marked `[unsourced]` and must not reach a brief.
Done when every `[n]` resolves to a list entry and no `[unsourced]` remains in a brief.
